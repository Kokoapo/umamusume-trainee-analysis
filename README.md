# Umamusume Trainee Analysis
Data analysis using the [UmaMusume Trainee Dataset](https://www.kaggle.com/datasets/kokoapo/umamusume-trainees/data)

## How to Run

1. Download the dependencies using ```pip install -r requirements.txt```
2. Use ```streamlit run main.py``` in the root folder
3. The streamlit server will be open in your localhost
